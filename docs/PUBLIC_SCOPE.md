# Public Showcase Scope

This repository is intentionally not a full source mirror.

Included:

- architecture and engineering rationale
- selected verified behavior
- representative source samples
- performance and validation methodology

Excluded:

- private local configuration
- local machine data and logs
- internal planning/backlog material
- credentials or environment-specific values
- full application source and packaging infrastructure

The purpose is to make the engineering work inspectable without exposing the entire private development repository.
